# Student Center Demo

A clearly labeled personal-project mockup inspired by a university student portal.

## Safety / scope
- Not affiliated with the University of Northern Iowa.
- Does not collect, store, or transmit credentials.
- Login accepts any non-empty demo values and only stores a session flag in the browser.
- "Pay Now" is intentionally non-functional.
- Uses generic project branding instead of presenting itself as an official university service.

## Run locally
Open `index.html` in a browser, or serve the folder with any static server.

## Pages
- Demo Login
- Student Center
- Course List
- Payment Overview
- Account Details
